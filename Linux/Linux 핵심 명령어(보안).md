# 🐧 Linux Core Commands for Security Engineer

보안 솔루션 구축 및 유지보수 시 가장 많이 사용하는 핵심 명령어 리스트.

---

## 1. 시스템 상태 모니터링 (장애 진단)
* **`top`** / **`htop`** : CPU 및 메모리 점유율 실시간 확인 (범인 프로세스 검거)
* **`df -h`** : 디스크 용량 확인 (로그 파일로 인한 디스크 풀 상태 점검)
* **`free -m`** : 메모리 여유 공간 확인
* **`uptime`** : 서버 가동 시간 및 부하율(Load Average) 확인

## 2. 네트워크 및 통신 점검 (연동 확인)
* **`netstat -lnp`** / **`ss -lnp`** : 현재 열려 있는 포트와 실행 중인 프로세스 확인
* **`telnet [IP] [Port]`** : 특정 포트가 방화벽에 막혀 있는지 테스트 (가장 많이 사용)
* **`ping [IP]`** : 네트워크 연결 가능 여부 확인
* **`ifconfig`** / **`ip addr`** : 서버의 IP 주소 및 네트워크 인터페이스 확인
* **`curl -v [URL]`** : 웹 기반 API 연동이나 외부 통신 상태 상세 확인

## 3. 프로세스 관리
* **`ps -ef | grep [서비스명]`** : 특정 보안 솔루션 프로세스가 실행 중인지 확인
* **`kill -9 [PID]`** : 응답 없는 프로세스 강제 종료
* **`systemctl status/start/stop [서비스]`** : 시스템 서비스 상태 관리

## 4. 로그 분석 및 파일 탐색 (트러블슈팅)
* **`tail -f [파일명]`** : 실시간으로 쌓이는 로그 모니터링 (장애 발생 시 필수)
* **`grep -i "error" [파일명]`** : 특정 키워드(에러 등) 검색 (`-i`는 대소문자 무시)
* **`find / -name [파일명]`** : 흩어져 있는 설정 파일(`conf`) 위치 찾기
* **`less`** / **`more`** : 대용량 로그 파일을 페이지 단위로 읽기 (메모리 절약)

## 5. 권한 및 파일 관리 (설치/배포)
* **`chmod -R 755 [디렉토리]`** : 폴더 및 하위 파일 권한 일괄 변경
* **`chown [유저]:[그룹] [파일명]`** : 파일 소유권 변경 (솔루션 실행 계정 설정)
* **`sudo`** : 관리자(root) 권한으로 명령어 실행
* **`tar -zxvf [파일명.tar.gz]`** : 솔루션 설치 패키지 압축 해제

## 6. 텍스트 편집 (설치 후 설정)
* **`vi`** / **`vim`** : 리눅스 표준 텍스트 편집기 (환경 설정 파일 수정 시 필수)
    * `i` : 입력 모드
    * `:wq` : 저장 후 종료
    * `:q!` : 저장하지 않고 강제 종료

## 🚩 쉘 스크립트 작성 맛보기
```bash
#!/bin/bash
# 보안 솔루션 프로세스가 죽었으면 다시 살리는 간단한 스크립트
ST=$(ps -ef | grep 'my_solution' | grep -v 'grep' | wc -l)

if [ $ST -eq 0 ]; then
    echo "솔루션이 죽어있습니다. 재시작합니다."
    /etc/init.d/my_solution start
else
    echo "정상 작동 중입니다."
fi
```
